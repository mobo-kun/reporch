# Contributing to Reporch

Thanks for helping. Reporch is used to publish real research, so correctness comes first.

## Ground rules

- **Never add real study data, personal data or non-open fonts** to the repository. The demo is fictional
  and generated by `tools/make_demo.py`.
- **Tests first.** Every change comes with a test; every bug fix starts with a failing test.
- **Keep it standard-library.** The core must run on Python 3.9+ with nothing installed. Optional extras
  (Playwright, pypdf) are always asked for and never required.
- **Generated files:** `templates/theme.css` comes from `scripts/reporch_lib/theme.py`;
  `references/analyses.{md,json}` come from `tools/catalogue_source.md` via `tools/build_catalogue.py`.
  Edit the source, then regenerate.

## Development

```bash
python3 -m unittest discover -s tests
```

```bash
python3 tools/make_demo.py && python3 scripts/reporch.py build examples/demo/reporch-projects/basket-checkout
```

## Pull requests

1. One change per pull request, with a short description of why.
2. Tests pass (CI runs them on Python 3.9 and 3.12).
3. Update `CHANGELOG.md` under an "Unreleased" heading.
4. For Persian text, follow the orthography in `modules/languages.md` (ZWNJ, Persian ی/ک and digits).

## Reporting bugs and ideas

Open an [issue](https://github.com/mobo-kun/reporch/issues) using the templates. Never attach real
participant data; describe the problem with made-up examples instead.
