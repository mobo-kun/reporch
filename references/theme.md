# Theme

Light theme only. The tokens are generated by `scripts/reporch_lib/theme.py` into
`templates/theme.css`; change the code, not the CSS.

## Page

- **Background:** white with a small, dense grey dot pattern (`--dot`, 1 px dots on a 12 px grid).
- **Glow:** one large, heavily blurred circle in `#9747FF` at 10% opacity behind the cover and first
  screen (`--glow`).
- **Ink:** `#1C1B22` for body text; `--ink-soft` for secondary text.
- **Credit line:** "Made with Reporch by Mobo · Behdad Morsalpoor" in the footer, 10 px, `--credit`
  (about 2.1:1). It is deliberately low contrast: it is a signature, not content, so it is the one
  exception to the AA rule.

## Palette

lightest step that reaches WCAG AA (4.5:1) on white: use it (`--<name>-text`) whenever the colour is
used for text, icons that carry meaning, or thin chart lines.

## Meaning

| Use | Token |
| --- | --- |
| Brand, links, headings accents | primary |
| Success, good result | green |
| Error, failure, critical issue | red |
| Warning, medium severity | amber |
| Information, neutral data | blue |
| Extra chart series | teal, indigo, pink, rose |

Chart series follow `--chart`: primary, green, amber, blue, rose, teal, indigo, pink, red. Never rely on
colour alone: every series also has a label or pattern.

## Brand

- **Default:** the palette above (the first adopters' brand).
- **Another brand:** the user's primary colour replaces `primary` (`theme.css(primary="#RRGGBB")`); the
  rest of the palette stays. Their logo goes in `assets/`.
- **Fonts:** Vazirmatn (bundled, OFL) for every language. A brand font, such as Lahzeh for the first
  adopters, is used only when the user puts its files in their project's `assets/fonts/`; it is never
  bundled with the skill.
